# task-management-app

## アプリ概要

Java Servlet/JSPとPostgreSQLを用いたチーム開発のタスク管理アプリです。  
タスクカードのドラッグ＆ドロップによるステージ管理やカレンダー表示など、実務を意識した機能を実装しています。  
4人チームで開発し、ローカル環境から仮想環境への構築・移築、GitHubを用いたチーム開発を経験しました。

---

## 主な機能

- **タスク管理**：タスクの追加・削除・完了操作
- **タスクカード**：ドラッグ＆ドロップによるタスクステージの変更
- **タスクカードの色変化**：期限に応じてカードの色が変わる
- **カレンダーページ**：各タスクを日付ごとに確認可能
- **マイタスクページ**：個人に紐づいたタスク・個人メモを表示
- **コメント・資料紐づけ**：タスクカードにコメントや簡単な資料を添付可能（実装中）
- **通知機能**：期限・プロジェクト召集時に通知（実装中）
- **ログイン機能**：個人・団体の権限付与を含むユーザー認証（実装中）

## 使用技術

| 技術 | 用途 |
|------|------|
| Java / Servlet / JSP | バックエンド全体 |
| PostgreSQL | データベース |
| Apache Tomcat | アプリケーションサーバー |
| Apache HTTP Server | Webサーバー |
| JDBC（DriverManager方式） | DB接続 |
| DAOパターン | データアクセス層の分離 |
| 仮想環境（VirtualBox等） | 開発・検証環境 |
| GitHub | バージョン管理・チーム共有 |
